# TouchGuides
!(/images/touchguides.png?aspect=2.9)
## 2023-Present

TouchGuides is a platform that allows hosts to create personalized recommendations for their guests, ensuring a unique and memorable stay. The platform provides everything hosts need to create and manage their guest experience.

As the founder of TouchGuides, I architected and developed the entire platform from the ground up, implementing modern web technologies and best practices.

### Technologies
- React
- Node.js
- TypeScript
- AWS
- Full Stack
- UI/UX
